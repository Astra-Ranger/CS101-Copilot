## [Page 12-13] 快速排序算法 (Fastsort) 核心逻辑
快速排序是分治（Divide and Conquer）范式的经典应用。

### 算法步骤
1.  **基线情况**：若数组长度 $ \le 1 $，直接结束。
2.  **标杆选择 (Pivot)**：通常选择数组最后一个元素。
3.  **划分 (Partition)**：将数组重排，使左侧元素均小于标杆，右侧均大于标杆。
4.  **递归调用**：分别对左、右子数组执行 `fastsort`。

## [Page 14-18] 从算法到程序：Fastsort 实现细节
```python
def fastsort(A, p, r):
    if p < r:
        q = partition(A, p, r) # 获取标杆索引
        fastsort(A, p, q-1)    # 递归处理小数组
        fastsort(A, q+1, r)    # 递归处理大数组
```

### Partition 函数的指针机制
*   **j 指针**：用于遍历数组寻找小于标杆的元素。
*   **i 指针**：用于维护“已处理的小元素区”的边界。
*   **交换逻辑**：当 `A[j] < pivot` 时，交换 `A[i]` 与 `A[j]` 并递增 `i`。

<!-- Page 19-23 -->
## [Page 19-23] Partition 逐步执行过程解析
以 `[8 6 3 4 9 5]` 为例，标杆值为 `5`：
1.  **初始**：`i, j` 均指向索引 0。
2.  **遍历**：`j` 遇到 `8` 和 `6`（大于 5），不做处理。
3.  **发现小元素**：`j` 指向 `3` 时，满足交换条件。
4.  **交换**：将 `A[2]`（即 3）与 `A[i]`（即 8）交换。数组变为 `[3 6 8 4 9 5]`，`i` 移向下一位置。
5.  **结束**：遍历完成后，将标杆值换至 `i` 所指位置，返回 `i`。
