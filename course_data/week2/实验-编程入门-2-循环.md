## [Page 5-7] 序列与列表：处理下标的艺术
在数学中我们常用 $ F_n $ 表示下标，而在 Python 中，我们利用**列表 (List)** 这一通用序列来实现。

### 1. 列表基本操作
*   **创建与初始化**：`fib = [0] * 11`。
*   **索引访问**：`fib[0]` 为第一个元素，`fib[-1]` 为最后一个元素。
*   **切片 (Slicing)**：`fib[1:3]` 获取索引 1 到 2 的子列表（含头不含尾）。

### 2. 斐波那契直线程序
```python
fib = [0] * 11
fib[0], fib[1] = 0, 1
fib[2] = fib[1] + fib[0]
# ... 逐行累加至 fib[10]
```
**思考**：当需要计算第 100 个数时，直线程序的局限性将完全暴露。


## [Page 8-9] 数据类型深度解析
Python 是动态类型语言，类型属于对象而非变量。
*   **不可变类型**：字符串 (`str`)、整数 (`int`)。尝试修改 `s[0] = 'b'` 会报错。
*   **可变类型**：列表 (`list`)。
*   **布尔值 (Bool)**：`True` / `False`（注意首字母大写）。


## [Page 10-14] 字符编码：文本在内存中的真相
计算机不存储字母，只存储比特。
*   **ASCII 码**：英文字符的标准化编码（如 `'A'` 对应 $ 65_{10} $，二进制为 `01000001`）。
*   **内置函数**：
    *   `ord('A')` $\rightarrow 65$（字符转编码）。
    *   `chr(65)` $\rightarrow$ `'A'`（编码转字符）。
*   **直线程序的缺陷**：违背 DRY 原则，程序长度正比于姓名长度，且包含大量魔数。


## [Page 15-20] 循环抽象：解决冗余与规模限制
循环通过重复执行代码块，使程序长度与问题规模脱钩。

### 1. while 循环
根据条件判断反复执行。
```python
i = 0
while i < len(name):
    sum = sum + ord(name[i])
    i = i + 1
```

### 2. for 循环与 range 函数
更简洁的遍历方式。`range(start, stop, step)` 生成索引序列。
```python
for i in range(len(name)):
    sum = sum + ord(name[i])
```


## [Page 21-25] 综合实践：手动实现十进制打印
本练习要求在不使用 `str()` 函数的前提下，通过 `%c` 占位符打印数值。

### 核心算法逻辑：取位
1.  **取余**：`sum % 10` 得到当前最低位数字。
2.  **整除**：`sum // 10` 丢弃已处理的最低位。
3.  **转换**：`chr(digit + ord('0'))` 将数值 $ 0-9 $ 转换为字符 `'0'-'9'`。
