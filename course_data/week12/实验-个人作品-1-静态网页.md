## [Page 4-5] 作品评价标准

### 1. 创造性 (4分)
鼓励个性化表达。完全依赖 AI 生成或无改动模仿的作品将得低分。高分作品需体现精心的原创设计。

### 2. 完成度 (4分)
要求功能完整且无严重 Bug。引用外部资源（图片、代码片段等）必须规范致谢，且外部代码占比需严格控制在 10% 以内。

## [Page 14-18] HTML 核心结构与开发环境

### 1. 网页骨架
```html
<html>
    <head>
        <meta charset="UTF-8">
        <title>网页标题</title>
    </head>
    <body>
        <!-- 页面可见内容 -->
    </body>
</html>
```

### 2. 开发方式
*   **云端模式**：利用平台内置 `http.server` 快速预览。
*   **本地模式**：使用 VS Code 编辑，通过 Chrome 浏览器直接打开 `.html` 文件。

<!-- Page 19-21 -->
## [Page 19-21] HTML 语法基础：标签、属性与元素
*   **标签 (Tag)**：成对出现，如 `<h1>...</h1>`，注意闭合标签的 `/`。
*   **属性 (Attribute)**：位于起始标签内，格式为 `name="value"`。
*   **元素 (Element)**：标签及其内容的整体。

---

<!-- Page 22-24 -->
## [Page 22-24] 文本内容排版

### 1. 标题与段落
*   `<h1>` 至 `<h6>`：定义不同级别的标题。
*   `<p>`：定义自然段。

### 2. 换行与分割
*   `<br>`：强制换行。
*   `<hr>`：水平分割线。

### 3. 文本格式化
*   `<b>`：加粗。
*   `<i>`：斜体。
*   `<sup>` / `<sub>`：上标与下标。

<!-- Page 25-27 -->
## [Page 25-27] 结构化数据展示：表格与列表

### 1. 表格 (Table)
使用 `<tr>`（行）与 `<td>`（单元格）构建。
```html
<table border="1">
    <tr><td>表头1</td><td>表头2</td></tr>
    <tr><td>数据1</td><td>数据2</td></tr>
</table>
```

### 2. 列表 (List)
*   **有序列表 (`<ol>`)**：自动生成序号。
*   **无序列表 (`<ul>`)**：显示项目符号。

## [Page 28-29] 用户交互基础：表单与输入框
表单 (`<form>`) 是收集用户输入的容器。

### 常用输入类型 (`<input>`)
*   `type="text"`：单行文本框。
*   `type="radio"`：单选框（相同 `name` 属性的为一组）。
*   `type="button"`：交互按钮。

<!-- Page 30-32 -->
## [Page 30-32] 页面分块逻辑：块级与内联元素
*   **块级元素 (`<div>`)**：独占一行，常用于页面布局与分块。
*   **内联元素 (`<span>`)**：嵌入行内，常用于局部样式控制（如计算器结果占位）。

<!-- Page 33-38 -->
## [Page 33-38] 样式美化：CSS 入门

### 1. 行内样式 (Method 1)
通过元素的 `style` 属性直接定义：`<h1 style="color: blue;">标题</h1>`。

### 2. 内部样式表 (Method 2)
在 `<head>` 中通过 `<style>` 标签统一管理：
```css
#id_name { background-color: gold; } /* 针对特定 ID 的样式 */
h2 { color: violet; }              /* 针对特定标签的样式 */
```

### 3. 通用属性
*   `id`：唯一标识符。
*   `class`：分组标识符。
*   `name`：元素名称。
