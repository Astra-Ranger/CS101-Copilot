  |---|---|---|
  | **自然科学：** | 研究物理世界的物质/能量运动过程 | 物质运动 |

# ②计算思维基础方法：活力法 PEPS

即，**Problem ↔ Encoding ↔ Process ↔ System** 的双向循环迭代　　　　　　　　　　　　　　是人机共生过程

1. **P：** 定义领域**问题**（**Problem** in target domain）  
   目标领域可是任一自然科学、社会科学、数学、计算机科学的领域

2. **E：** 将问题解法**建模**（**Encoding**）到赛博空间（cyberspace）中的计算过程，体现为算法或程序

3. **PS：** 计算**过程**（**Process**）在计算**系统**（**System**）上自动执行，得到问题答案

4. 映射回到目标领域，看问题是否解决；没有的话开始下一次迭代

---

|---|---|---|
| **人工**<br><br>人类社会各领域中的**问题 Problem** | **Encoding**<br>（Modeling）<br>**建模** | **自动执行**<br><br>计算**过程**<br>Computational **Process**<br><br>计算**系统**<br>Computing **System**<br><br>赛博空间 **Cyberspace** |

# 为什么渗透广？ 不是偶然的，业界提出了四个解释

- 乔姆斯基<span style="color:red">数字无穷性</span>原理
  - 任何人类语言的无穷含义都可以采用有限符号表示。因此，都可以通过有限的数字符号集表示，由计算机科学处理。

- 卡普<span style="color:red">计算透镜</span>命题
  - 很多自然界和人类社会的过程也是计算过程。计算机科学可以产生新视角、新方法、新价值。  
    Nature computes. Society computes.

- 巴贝扬<span style="color:red">黄金隐喻</span>
  - 计算速度（算力）是像黄金一样的硬通货，可以换成任何其他东西，包括新的功能、更好的性能、更容易使用、更好的产品、成本更低的服务，等等。

- 布兰<span style="color:red">蜜蜂隐喻</span>　　**21世纪<span style="color:red">授粉价值</span>（生态价值）越来越重要**
  - 信息技术就像蜜蜂一样，产生的两类价值，间接价值（授粉）比直接价值（蜂蜜）大得多
    - 授粉的经济价值是蜂蜜的经济价值的28-373倍
    - 2016年全球数字经济大约为11.5~24万亿美元，远大于该年的信息产业市场（约3.4~4.3万亿美元）

# 体现ABC： 计算斐波那契数F(n)

$$
F(n)=
\begin{cases}
0 & n=0 \\
1 & n=1 \\
F(n-1)+F(n-2) & n>1
\end{cases}
$$

## 手工算

无计算思维

```text
用纸和笔手工逐步计算

F(0)= 0,
F(1)= 1,
F(2)= F(1)+F(0) =1+0=1
F(3)= F(2)+F(1) = 1+1 = 2
F(4)= F(3)+F(2) = 3
F(5)= F(4)+F(3) = 5
F(6)= F(5)+F(4) = 8
F(7)= F(6)+F(5) = 13
F(8)= F(7)+F(6) = 21
F(9)= F(8)+F(7) = 34
F(10)= F(9)+F(8) = 55
```

体现A：不精准、快

```python
import math    # fib.binet.py

def f(n):
    sqrt5 = math.sqrt(5)
    phi = (1+sqrt5)/2
    return (phi**n-(1-phi)**n)/ sqrt5
```

## 2.2.2 状态机示例：已知北京日出时间，求喀什日出时间

- 2022年12月5日，北京日出时间=07:20
  - 半夜0点 = 0 秒
  - **7点20分 = 7\*3600 + 20\*60 = 26400 秒**
- 问题：预测喀什日出时间。
- 手工计算的<u>逐步过程</u>

1. 求地球自转速度 $S$。北纬40度线上任意一点的自转速度是  
   $S = 40000 \times \cos(40) / (24 \times 3600) = 355$ 米/秒。
2. 求经度之差 $L$。北京与喀什的经度之差是  
   $L = 116 - 76 = 40$ 度，即360经度的 $1/9$。
3. 求两点的距离 $D$。北京与喀什的距离是  
   $D = 40000 \times \cos(40) / 9 = 3405$ 千米。
4. 求两点的时差 $T$。北京与喀什的时差是  
   $T = 3405 / 355 = 9592$ 秒，即2小时39分52秒。
5. 喀什的日出时间是 $26400 + 9592 = 35992$ 秒，  
   或早上7点20分 + 2小时39分52秒，即早上9点59分52秒。

- 检验：
  - 中央气象台：  
    2022年12月5日，喀什的日出时间是早上9点59分。

# 本质：用状态机刻画自动计算的逐步过程

通过一个**变量赋值转移序列**来表示（这个有规则的状态转移空间，称为系统、状态机、自动机）

- **状态**（state）：任何时刻，系统的变量赋值称为自动机的状态（state）
- **步骤**（step）：一次状态转移（state transition）
  - 即状态机从当前状态转移到下一状态
  - 如步骤1，状态I→状态II，变量S的赋值从?变为355，其他变量值不变

> 步骤1：\(S = 40000 \times \cos(40) / (24 \times 3600) = 355\) 米/秒

- **过程**（process）：状态机的一系列状态转移，从初始状态变换到最终状态
  - **状态I（初态）→ II → III → IV → 状态V（终态）**

# 3. 前三周初步掌握计算机科学的入门词汇

- **数**（number）也称为**数值**（value）或**值**。计算机科学将所有事物表示为数，并对各种数进行操作，从输入数值产生输出数值。
- 当代流行的位置计数法将一个数表示为一个数字或多个相邻的一组数字，其中每个**数字**（digit）所在的位置称为其**数位**，简称**位**。例如，十进制数表示为0，1，2，3，4，5，6，7，8，9十个数字的相邻组合。十进制数516由三个十进制数字组合而成，分别是百位的5、十位的1、个位的6，它们合起来代表五百一十六这个数值。
- **比特**（bit或binary digit）是二进制数位，或取值为0或1的数字。例如，二进制数1110有四个比特，分别是1、1、1、0。与二进制数1110等价的十进制数是14。
- **数字符号**（digital symbol）是可由一个或多个比特表示的记号，用于表示一个抽象或具体的事物。每一个数字符号本质上都会表示为一个二进制数。基本数值往往用一个**字**（word）表示，所需比特数称为**字长**（word length）。例如，在64位计算机中，一次加法是两个64比特数的加法。
- **字节**（byte）特指八个相邻比特构成的数字符号，或该符号所需存储空间。字节的字长是8。
- **字符**（character）是一类特殊的数字符号，表示某种文明的文本（text）。课程重点关注两类字符集：表示英文文本的ASCII字符集，包含A、b、7、$等字符；以及表示全球文本的Unicode字符集，包含A、⊙、😊、中、￥等字符。
- **算法**（algorithm）是一组有穷的规则，给出求解问题的数字符号操作步骤序列。
- **程序**（program）是算法的编程语言表示，换言之，程序是采用某种计算机语言表示的算法。**代码**（code）是指一部分程序，可大到包括整个程序。**软件**（software）包括程序及说明程序的**文档**（document）。
- **数据**（data）是一组数字符号。
- 当程序或数据被持续存放在计算机中时，它们被称为**文件**（files）。持续存储是指，当计算机下电后，数据文件和程序文件不会丢失。
- **数据类型**（data type）是特定类型的数据在计算机中的表示及其操作规则。例子包括：布尔值、整数、字符串、列表，等。
- **控制抽象**（control abstractions）说明多个操作的执行顺序。课程主要关注五种控制抽象：运算优先级、串行顺序、条件判断、循环、函数调用（包括递归调用）。

# 程序有三类错误（bug）；都需要排错（debug）

- Python解析器（系统）会报错的两类

①语法错误（syntactic error）

  - 程序不符合Python语言的语法规则，例如：`A = 3 +`

②语义错误（也有学者称为静态语义错误，static semantic error）

  - 程序符合Python语言的语法规则，但无意义
    - `A = 3 + " Red "`　　# 类型错误
    - `T = D / S`　　# S=0.0 除数为零错误

- 系统不会报错的一类（<span style="color:red">最糟糕的错误</span>）

③算法错误（程序实现了错误的算法，但“圆满”运行并产生结果）

  - 程序符合语法规则且有意义，但不符合用户意图
    - 正确语句应该是 `T = D / ` <span style="color:red">`S`</span>，但程序代码写成了 `T = D / ` <span style="color:red">`B`</span>
    - 正确语句应该是 `B = 7*`<span style="color:red">`3600`</span>` + 20*60`，但写成了 `B = 7*`<span style="color:red">`360`</span>` + 20*60`

- <span style="color:red">数</span>（number）也称为<span style="color:red">数值</span>（value）或<span style="color:red">值</span>。计算机科学将所有事物表示为数，并对各种数进行操作，从输入数值产生输出数值。
- 当代流行的位置计数法将一个数表示为一个数字或多个相邻的一组数字，其中每个<span style="color:red">数字</span>（digit）所在的位置称为其<span style="color:red">数位</span>，简称<span style="color:red">位</span>。例如，十进制数表示为0，1，2，3，4，5，6，7，8，9十个数字的相邻组合。十进制数516由三个十进制数字组合而成，分别是百位的5、十位的1、个位的6，它们合起来代表五百一十六这个数值。
- <span style="color:red">比特</span>（bit或binary digit）是二进制数位，或取值为0或1的数字。例如，二进制数1110有四个比特，分别是1、1、1、0。与二进制数1110等价的十进制数是14。
- <span style="color:red">数字符号</span>（digital symbol）是可由一个或多个比特表示的记号，用于表示一个抽象或具体的事物。每一个数字符号本质上都会表示为一个二进制数。基本数值往往用一个<span style="color:red">字</span>（word）表示，所需比特数称为<span style="color:red">字长</span>（word length）。例如，在64位计算机中，一次加法是两个64比特数的加法。
- <span style="color:red">字节</span>（byte）特指八个相邻比特构成的数字符号，或该符号所需存储空间。字节的字长是8。
- <span style="color:red">字符</span>（character）是一类特殊的数字符号，表示某种文明的文本（text）。课程重点关注两类字符集：表示英文文本的ASCII字符集，包含A、b、7、$等字符；以及表示全球文本的Unicode字符集，包含A、⊙、😊、中、￥等字符。
- <span style="color:red">算法</span>（algorithm）是一组有穷的规则，给出求解问题的数字符号操作步骤序列。
- <span style="color:red">程序</span>（program）是算法的编程语言表示，换言之，程序是采用某种计算机语言表示的算法。<span style="color:red">代码</span>（code）是指一部分程序，可大到包括整个程序。<span style="color:red">软件</span>（software）包括程序及说明程序的<span style="color:red">文档</span>（document）。
- <span style="color:red">数据</span>（data）是一组数字符号。
- 当程序或数据被持续存放在计算机中时，它们被称为<span style="color:red">文件</span>（files）。持续存储是指，当计算机下电后，数据文件和程序文件不会丢失。
- <span style="color:red">数据类型</span>（data type）是特定类型的数据在计算机中的表示及其操作规则。数据类型例子：布尔值、整数、字符、数组、切片。
- <span style="color:red">控制抽象</span>（control abstractions）说明多个操作的顺序。课程主要关注五种控制抽象：运算优先级、串行顺序、条件判断、循环、函数调用（包括递归调用）。

**字节**（byte），**字符**（character），  
**数字符号**（digital symbol），**操作**（operation）

- 计算机的最小信息单位是**比特**，即二值数字（**binary digit**，简称bit）

- 另一个常用信息单位是**字节**（byte），即一组8比特信息
  - 例如，十进制数1032的可用11比特表示：`10000001000`  
    添加5个前导零，
  - 十进制数1032可用16个比特，即两个字节，表示：`0000010000001000`

- **字符**（character）
  - 每个英文字符可用一个字节表示，如加号‘+’表示为$00101011_2$或$43_{10}$

- **数字符号**（digital symbol）是可由一个或多个比特表示的记号，用于表示一个抽象或具体的事物
  - 例如，$1032 = 516 + 516$中，516、1032是数字符号；=、+是数字符号；甚至整个加法计算过程，也是数字符号

- **操作**（operation，有时也称为运算）将输入数字符号（操作数）变成输出数字符号（结果）
  - 加、减、乘、除是操作
  - 算盘求和例子中，“六上一 去五 进一”这一步的整体是操作，“六上一”是微操作（micro-operation）
  - 整个算盘加法计算过程也是操作
