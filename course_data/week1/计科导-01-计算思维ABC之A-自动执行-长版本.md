## [Page 14-17] 计算思维基础方法：PEPS 活力法

PEPS 法是人机共生的循环迭代过程：

1.  **P (Problem)**：定义领域问题。
2.  **E (Encoding)**：将解法建模到赛博空间（算法或程序）。
3.  **P (Process)**：计算过程在系统上自动执行。
4.  **S (System)**：计算系统支持执行。

### 应用实例
*   **信息隐藏**：将文本隐藏在图像中。
*   **创造性表达**：学生通过网页编程实现动态作品（如“猫猫指挥家”、“宇宙沙箱”）。

## [Page 37-38] 计算思维 ABC：以斐波那契数列为例

### 数学定义
$$
F(n) = 
\begin{cases} 
0 & n=0 \\ 
1 & n=1 \\ 
F(n-1)+F(n-2) & n>1 
\end{cases}
$$

### 程序实现对比

#### 1. 体现 A（自动执行）：利用 Binet 公式（不精准但快）
```python
import math
def f(n):
    sqrt5 = math.sqrt(5)
    phi = (1 + sqrt5) / 2
    return (phi**n - (1 - phi)**n) / sqrt5
```

#### 2. 体现 AB（精准但极慢）：递归实现
```python
def f(n):
    if n < 2: return n
    return f(n-1) + f(n-2)
```

#### 3. 体现 ABC（精准且快）：带缓存的递归
```python
from functools import lru_cache
@lru_cache
def f(n):
    if n < 2: return n
    return f(n-1) + f(n-2)
```

<!-- Page 82-87 -->
## [Page 82-87] 直线程序（Straight-Line Programs）

直线程序按静态顺序执行，没有分支或循环。

### 喀什日出时间计算程序
```python
import math
B = 7 * 3600 + 20 * 60            # 北京日出秒数
length = 40000 * math.cos(40)      # 北纬 40 度线长度
S = length / (24 * 3600)           # 自转速度
D = length * (116 - 76) / 360      # 经度差对应的距离
T = D / S                          # 时差
print("喀什的日出时间是：", B + T)
```

### 错误类型
