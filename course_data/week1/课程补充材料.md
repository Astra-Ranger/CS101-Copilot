# 计算机科学导论：课程补充材料

## [Page 1-2] Shell 常用命令与终端快捷键

**Shell** 是一种命令行解释器，通过接收用户输入的命令并调用系统资源执行。在 VS Code 中，可通过快捷键 `Ctrl + \`` 打开集成终端。

### 1. 核心文件与目录操作命令
| 命令 | 功能描述 | 典型应用示例 |
|---|---|---|
| `pwd` | 打印当前工作目录路径 | `pwd` |
| `ls` | 列出当前目录下的文件与子目录 | `ls -a` |
| `cd` | 切换当前工作目录 | `cd ..` (上级), `cd project` (子目录) |
| `mkdir` | 创建新文件夹 | `mkdir lab_session` |
| `cat` | 查看文件内容并输出到终端 | `cat hello.py` |
| `cp` | 复制文件或目录 | `cp config.py backup.py` |
| `mv` | 移动文件或重命名 | `mv old.py new.py` |
| `rm` | 删除文件或目录 | `rm file.txt`, `rm -rf folder` (强制删除) |
| `python3` | 执行脚本或进入交互式 REPL | `python3 script.py` |

### 2. 终端高效操作快捷键
*   **`TAB` 键**：自动补全路径或文件名（双击可列出匹配项）。
*   **上/下箭头**：快速浏览并重用历史命令。
*   **`Ctrl + C`**：强制中断当前正在运行的进程。
*   **`Ctrl + D`**：优雅退出 Python 交互式会话。
*   **`Ctrl + S`**：在编辑器中保存当前文件。


## [Page 3] Python 字符串格式化：占位符与修饰符

Python 使用 `%` 运算符实现字符串的动态填充。
*   **基本语法**：`"模板字符串" % (值1, 值2, ...)`

### 1. 常用占位符列表
| 占位符 | 适用数据类型 |
|---|---|
| `%s` | 字符串（自动调用 `str()` 转换） |
| `%c` | 单个字符 |
| `%d` | 十进制整数 |
| `%f` | 十进制浮点数 |
| `%x` / `%X` | 十六进制整数（小写/大写） |
| `%%` | 输出字面量 `%` 符号 |

### 2. 格式化修饰符
*   **精度控制**：`%.2f`（保留两位小数）。
*   **对齐与宽度**：`%-10s`（左对齐，总宽 10 位）。
*   **零填充**：`%05d`（不足 5 位时前面补 0）。


## [Page 4] Python 常用转义码序列

在定义字符串字面量时，反斜杠 `\` 用于引导转义序列以表达特殊字符。

| 转义序列 | 实际含义 |
| --- | --- |
| `\\` | 输出一个反斜杠 `\` |
| `\'` | 输出单引号 `'` |
| `\"` | 输出双引号 `"` |
| `\n` | 换行符（Line Feed） |
| `\t` | 水平制表符（Tab） |
| `\<newline>` | 续行符（代码跨行书写但逻辑连续） |


## [Page 5-7] 英文文本字符集：ASCII 编码标准

ASCII 码是计算机处理文本的基础，包含控制字符与可打印字符。

### 1. 关键控制字符 (0-31)
用于控制传输及终端行为，不直接显示。
*   `0x00 (NUL)`：空字符。
*   `0x07 (BEL)`：响铃。
*   `0x09 (HT)`：水平制表符。
*   `0x0A (LF)`：换行。
*   `0x0D (CR)`：回车。

### 2. 核心可打印字符 (32-127)
涵盖了数字、英文字母及常用符号。
*   **符号类**：`0x20` (空格), `0x24` ($), `0x25` (%), `0x2B` (+), `0x3D` (=)。
*   **数字类**：`0x30 - 0x39` (0 - 9)。
*   **字母类**：
    *   大写字母：`0x41 (A) - 0x5A (Z)`。
    *   小写字母：`0x61 (a) - 0x7A (z)`。
*   **其他**：`0x5C` (\\), `0x5F` (_), `0x7E` (~), `0x7F` (DEL)。
