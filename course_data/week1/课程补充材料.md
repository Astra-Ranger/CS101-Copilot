# shell常见命令与快捷键

## shell

**shell**是一个命令行解释器，它输出一个提示符，等待输入一个命令行，然后执行这个命令。

我们通过**终端**（`terminal`）将命令输入到`shell`中。在`vscode`中，打开终端的快捷键为`ctrl` + `` ` ``（反引号）。

```bash
/home/coder $ |
```

`$`是命令行**提示符**，闪烁的`|`是**光标**，命令行提示符前的`/home/coder`为当前所在的目录。

# Python 占位符

`Python` 中，可以使用 `%` 运算符在字符串中插入值。其基本语法结构为：

---

<!-- Page 3 -->

python
"模板字符串" % (值1, 值2, ...)
```

运算符的左侧为需要进行格式化的字符串，字符串中可包含一个或多个需要转换的目标。这些目标以 `%` 开头，如 `%c`，`%d` 等。

运算符为要插入的值：

- 单个值可直接放置
- 多个值需封装为元组形式

```python
>>> H = "鹤壁"
>>> B = 8
>>> "我的家乡是%s" % H
'我的家乡是鹤壁'
>>> "%s的日出时间是%d点" % (H, B)
'鹤壁的日出时间是8点'
>>>
```

## 部分占位符

| 占位符 | 描述 |
|---|---|
| `%s` | 字符串（将对象转换为字符串） |
| `%c` | 字符 |
| `%d` | 十进制数字 |
| `%f` | 十进制浮点数 |
| `%x` | 十六进制整数，小写 |
| `%X` | 十六进制整数，大写 |
| `%%` | 字面量 `%` 符号 |

## 部分修饰符

- 宽度：`%10s` 表示最小宽度为10
- 精度：`%.2f` 表示浮点数保留2位小数
- 对齐：`%-10s` 表示左对齐，宽度为10
- 填充：`%010d` 表示用0填充，宽度为10

# Python转义码

如果标注 `r` 或 `R` 前缀，字符串和字节串字面值中，可用如下转义序列（部分）：

---

<!-- Page 4 -->

| 转义序列 | 含义 |
| --- | --- |
| `\<newline>` | 忽略反斜杠与换行符 |
| `\\` | 反斜杠（`\`） |
| `\'` | 单引号（`'`） |
| `\"` | 双引号（`"`） |
| `\n` | ASCII 换行符（LF） |
| `\t` | ASCII 水平制表符（TAB） |

当需要将长字符串跨行书写但保持内容连续时，可在行尾使用反斜杠，如：

```python
>>> 'This is a very long string that \
... spans multiple lines in the code.
'This is a very long string that spans multiple lines in the code.'
```
