# 计算思维基础方法：活力法P<span style="color:red">E</span>PS

- 人工建模（Encoding）<span style="color:red">到赛博空间</span>；自底向上

1. 定义领域<span style="color:red">问题</span>（<span style="color:red">P</span>roblem in target domain）  
   目标领域可是任一自然科学、社会科学、数学、计算机科学的领域

2. 将问题解法<span style="color:red">建模</span>（<span style="color:red">E</span>ncoding）到赛博空间中自底向上的计算过程，体现为程序

3. 计算<span style="color:red">过程</span>（<span style="color:red">P</span>rocess）在计算<span style="color:red">系统</span>（<span style="color:red">S</span>ystem）上自动执行，得到问题答案

4. 映射回到目标领域，看问题是否解决；没有的话开始下一次迭代

$$
F(n)=
\begin{cases}
0 & n=0 \\
1 & n=1 \\
F(n-1)+F(n-2) & n>1
\end{cases}
$$

先求F(0)、F(1)、F(2) …，最后求F(10)

自底向上  
(bottom up)  
建模

$$
f_n=
\begin{cases}

\end{cases}
$$

  - 可交互式显示，也可用在程序文件中用 `print`

  - `math.cos`函数，参数应该采用弧度值  
    `math.cos(40*3.14159/180)`,

    - 圆周360度 = $2\pi$ 弧度
    - 弧度值 = 角度值 * $\pi$ / 180
    - 40度对应的弧度值： $40 * \pi / 180$

  `length = 40000*math.cos(40*3.14159/180)`

# 纠正SunRise1.py程序的错误

- 明明有错，结果怎么是对的？
  - T = D/S抵消了length变量，length没起作用
    - 计算过程用不着这么复杂，3行代码就够了

- 重新建模（P<span style="color:red">E</span>PS）简化计算过程
  1. 北京日出时间：7点20分 = 7\*3600+20\*60 = 26400 秒
  2. 北京与喀什的经度之差是：L = 116-76 = 40度
  3. 北京与喀什的时差是：T = L\*240 = 9600秒  
     因为地球自转一周（360度）耗时24小时  
     每经度耗时：24\*3600 秒 / 360度 = 240 秒/度
  4. 喀什的日出时间是：26400+9600=36000秒，  
     或早上7点20分+2小时40分，结果为早上10点00分

- 简化后的程序

```python
B = 7*3600 + 20*60    # 简化后的SunRise1.py
T = (116-76) * 240    # 每经度增加240秒
print("喀什的日出时间是： ", B + T)
```
