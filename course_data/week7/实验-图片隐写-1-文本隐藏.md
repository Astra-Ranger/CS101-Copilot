## 文本隐藏算法——对应 `hide.py`

- **输入：** 文本文件 `hamlet.txt` 与图像文件 `autumn.bmp`。
- **输出：** 新图像文件 `doctoredAutumn.bmp`，它隐藏了 `hamlet.txt` 的全部内容，且与原图像文件 `Autumn.bmp` 无肉眼可见差别。
- **步骤：**

1. 将文本文件 `hamlet.txt` 读进变量 `t`  # `t` 即 `text`
2. 将图像文件 `Autumn.bmp` 读进变量 `p`  # `p` 即 `picture`
3. 将 `hamlet.txt` 的文件长度 `length` 隐藏到变量 `p` 的像素阵列的前 32 个字节；`length` 是 64 比特整数，每两比特放入像素阵列的一个字节的最低两比特
4. 将 `hamlet.txt` 的文件内容隐藏到变量 `p` 的 `Pixel Array` 的剩余字节
5. 将 `p` 写到新文件 `doctoredAutumn.bmp`

## 文本恢复算法——对应 `show.py`

- **输入：** 图像文件 `doctoredAutumn.bmp`。
- **输出：** `recovered.txt`，其内容与 `hamlet.txt` 应该无差别。
- **步骤：**

1. 将图像文件 `Autumn.bmp` 读进变量 `p`
2. 从变量 `p` 的 `Pixel Array` 的前 32 个字节提取文本文件长度
3. 从变量 `p` 的 `Pixel Array` 的剩余字节提取文本内容，绑定到变量 `t`
4. 将 `t` 写到新文件 `recovered.txt`

# 1. 如何在计算机中表示图片？

- 本实验中 **BMP** 图片的每个像素用 **3** 字节编码（**24** 位）
- 图片像素阵列的起始地址在 **54** 字节

| 结构名称 | 大小 | 作用 |
|---|---|---|
| `File Header` | 14 字节 | 表明是 BMP 文件，存储 BMP 文件的通用信息，例如图片大小 |
| `BMP Info Header` | 40 字节 | 存储 BMP 文件的详细信息，例如该图片的宽和高 |
| `Pixel Array` | 3*宽*高 字节 | 像素阵列 |

```text
0
1        BMP File Header
...
13
14
15       BMP Info Header
...
53
54  ← Pixel Array 起始地址
55
56       Pixel Array
...
```

# 掩码机制 (mask machenism)

- 输入：00111111, 00101010；输出：00111110
  - 如何保留第一个数的前6位，第二个数的后2位，并拼接在一起？

```text
x = 63                  # 把 63=00111111 赋值给变量x
v = 42                  # 把 42=00101010 赋值给变量v
v = v & 0x3             # 按位与，仅保留v的最低2位
x = x & 0xFC            # 按位与，清除x的最低2位，保留最高6位
x = x | v               # 按位或，得到最终结果
```

```text
x = 0b00111111
v = 0b00101010
v = 0b00101010 & 0b00000011   # = 00000010
x = 0b00111111 & 0b11111100   # = 00111100
x = 0b00111100 | 0b00000010   # = 00111110

# 实验原理

- 图片由像素构成，一个像素使用3个字节存储
- 对于像素阵列，修改每个字节的最低位或最低2位几乎没有视觉差异
- 可以使用掩码机制保留第一个数的前6位，第二个数的后2位
  - 输入：<span style="color:#0070C0;font-weight:bold;">001111</span>11, 001010<span style="color:red;font-weight:bold;">10</span>；输出：<span style="color:#0070C0;font-weight:bold;">001111</span><span style="color:red;font-weight:bold;">10</span>

# 步骤3. 隐藏文本长度

  不隐藏文本长度是否可行？

- 文本长度 `len(t)` 是一个整数
  - 计算机中一般常用 64 比特（8字节）表示一个整数
  - 在图像的字节数据中，每个字节表示一个颜色通道
  - 每个图像字节的最低两个比特用于隐藏数据
  - 文本长度是一个 64 比特数据，使用 $64/2=32$ 个图像字节来隐藏

S = 54  # 标准 BMP 头大小

# 6. modify()

- `modify(value, pix, idx, size)`
- 作用：将 `value` 隐藏到 `pix[idx:idx+size]`
  - `modify(t[i], p, offset, C), 当i=0时`
    - `value = t[0] = 'H' = 72 = 0b01001000`
    - `offset = S + T + C * i = 86`
    - `C = 4`
    - 第一次循环：将 `00` 写入 `p[86]` 的最低 2 比特
    - 第二次循环：将 `10` 写入 `p[87]` 的最低 2 比特
