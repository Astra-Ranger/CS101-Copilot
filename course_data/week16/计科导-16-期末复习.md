# 计算机科学导论：期末复习与知识融会贯通

## [Page 1-3] 期末复习导引与建议
期末复习不仅是为了考试，更是为了增强对计算思维（CT）的体认，提升自学能力与想象力。建议系统复习大班课与小班课课件，并辅以教科书内容。

### 复习目标
1.  **增强自信**：体认从 0 到 1 的跨越。
2.  **融会贯通**：建立知识点之间的深层联系。
3.  **成绩提升**：熟悉闭卷笔试的题型与范围。


## [Page 4-5] 什么是计算机科学：研究抽象与现实的交汇
计算机科学（CS）是研究计算机及其能力的学科，涵盖了抽象计算机的极限、真实计算机的构造以及广泛的计算机应用。

### 核心关键词映射
*   **符号与操作**：有限状态机、图灵机。
*   **抽象创造**：各种编程抽象。
*   **算法研究**：快速排序、分治范式。
*   **人工结构**：个人网页作品。
*   **指数增长**：斐波那契递归程序、诺德豪斯定律。
*   **基本极限**：P 与 NP、图灵不可计算问题、哥德尔不完备定理。


## [Page 6-8] 计算思维基本方法：PEPS 活力法
PEPS 法是连接现实世界与赛博空间的桥梁。

### 1. 核心流程
*   **P (Problem)**：定义领域问题。
*   **E (Encoding)**：建模到信息空间。
*   **P (Process)**：刻画计算过程（算法、程序）。
*   **S (System)**：运行计算系统（冯·诺依曼模型）。

### 2. 精力占比示例
*   **斐波那契程序**：侧重于计算过程（78%）与系统（20%）。
*   **个人作品开发**：侧重于问题定义（40%）与计算过程（30%）。


## [Page 9] 计算思维的十个维度：Acu-Exams-CP
| 维度 | 释义 |
|---|---|
| **A (Automatic)** | **自动执行**：离散步骤的自动化。 |
| **C (Correctness)** | **正确性**：比特精准的定义。 |
| **U (Universality)** | **通用性**：求解任意可计算问题。 |
| **E (Effectiveness)** | **构造性**：构造有效解决问题的方法。 |
| **X (Complexity)** | **复杂度**：算法的时间与空间成本。 |
| **A (Abstraction)** | **抽象化**：以一耦万的应用系统。 |
| **M (Modularity)** | **模块化**：模块的规律性组合。 |
| **S (Seamless)** | **无缝衔接**：计算过程的流畅执行。 |
| **C (Connectivity)** | **连接性**：处理连接体而非单体。 |
| **P (Protocol)** | **协议栈**：节点间的交互规则。 |


## [Page 10] 知识融会贯通：万物皆比特
在计算机系统中，所有信息终究以二进制表示。
*   **数**：原码、补码、浮点数。
*   **字符**：ASCII、Unicode（表示层）、UTF-8（实现层）。
*   **程序**：Python 源码文本、处理器机器指令。


## [Page 11] 算法融会贯通：快速排序（Quicksort）
通过分治范式与随机范式优化排序性能。
*   **核心逻辑**：随机选取基准数（Pivot），通过 `partition` 进行左右划分。
*   **性能分析**：
    *   平均时间复杂度：$ O(N \log N) $。
    *   最坏时间复杂度：$ O(N^2) $（当划分极度不平衡时）。
    *   空间复杂度：$ O(N) $（In-place 原地排序）。


## [Page 12-19] 系统融会贯通：从加法逻辑到时序电路

### 1. 组合逻辑：全加器 (Full Adder)
*   **逻辑定义**：$ Z = X \oplus Y \oplus C_{in} $。
*   **间接抽象**：通过引入 $ P $（传播）与 $ G $（生成）信号，可推广至高性能先行进位加法器。

### 2. 时序逻辑：四位串行加法器设计
通过时钟同步电路，在四个周期内复用一位全加器完成计算。

#### 设计四步法
1.  **确定状态**：需要一个 D 触发器存储当前进位 $ C $。
2.  **套用结构**：建立由组合电路 $ F $（生成输出 $ Z $）和 $ G $（生成下一状态 $ C_{next} $）以及 D 触发器组成的标准模型。
3.  **推导表达式**：
    *   **状态转移图** $\rightarrow$ **真值表**。
    *   **输出逻辑**：$ Z = X \oplus Y \oplus C $。
    *   **下一状态逻辑**：$ C_{next} = (X \cdot Y) \lor ((X \oplus Y) \cdot C) $。
4.  **验算验证**：通过具体的二进制输入（如 $ 11+9 $）按时钟周期逐步验算结果。
