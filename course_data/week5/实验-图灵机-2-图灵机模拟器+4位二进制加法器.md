## [Page 3-11] 命题逻辑基础：真值表的构建与分析

真值表是布尔函数 $ f:\{0,1\}^n \to \{0,1\} $ 的直接表格式表达。

### 1. 构建标准真值表
*   **表头设计**：列出所有输入变量（如 $ P, Q $）及复合命题表达式。
*   **赋值顺序**：对于 $ n $ 个变量，表身共有 $ 2^n $ 行，按二进制递增顺序赋值（如 $ 00, 01, 10, 11 $）。
*   **核心逻辑关系**：
    *   **蕴含 ($ P \to Q $)**：仅在“真推假”时为假。
    *   **等价性分析**：通过真值表可以证明“原命题等价于其逆否命题”，这一结论不依赖于具体的背景知识。


## [Page 13-18] 逻辑设计实例：双路复用器与全加器

### 1. 双路复用器 (MUX)
MUX 根据控制输入 $ S $ 选择数据 $ X $ 或 $ Y $。
*   **逻辑表达式**：$ Z = (\neg S \land X) \lor (S \land Y) $。

### 2. 全加器 (Full-Adder)
全加器是构建复杂计算系统的基石。
*   **输入**：$ X, Y, C_{in} $。
*   **输出**：和 $ Z = X \oplus Y \oplus C_{in} $，进位 $ C_{out} = (X \land Y) \lor (C_{in} \land (X \oplus Y)) $。


## [Page 19-20] 图灵机模拟器：规则读取与数据建模
图灵机模拟器的核心任务是存储并查询转移函数 $ \delta $。

### 规则结构化
我们将每一条转移规则拆分为两部分：
*   **构象 (Key)**：`(当前状态, 读入符号)`。
*   **动作 (Value)**：`(写下符号, 移动方向, 下一状态)`。


## [Page 21-25] Python 数据结构应用：元组与列表

### 1. 元组 (Tuple)
元组是不可变的序列，非常适合存储固定的规则条目。利用**序列解包**，可以简洁地提取规则内容：
```python
# 序列解包示例
out_sym, direct, next_st = action
```

### 2. 列表 (List) 模拟纸带
虽然图灵机纸带是无限的，但在模拟器中，我们常用一个足够长的列表来模拟，并使用 `"B"` 填充空白格。


## [Page 26-30] 高效查询：利用字典 (Dict) 存储规则
相比于遍历列表，使用字典可以实现 $ O(1) $ 时间复杂度的规则匹配。

```python
def read_table():
    table = {}
    while True:
        line = input().strip()
        if line == "END": break
        cur_s, in_s, out_s, direct, next_s = line.split()
        # 以构象元组为键，动作元组为值
        table[(cur_s, in_s)] = (out_s, direct, next_s)
    return table
```


## [Page 31-33] 核心模拟逻辑：执行循环
模拟器的 `simulate` 函数通过循环驱动状态机的流转，直至进入停机状态 `qa`。

```python
while cur_state != "qa":
    # 查找并执行规则
    out_sym, direct, next_st = table[(cur_state, tape[pos])]
    tape[pos] = out_sym
    # 更新读写头位置
    pos = pos + 1 if direct == "R" else pos - 1
    cur_state = next_st
```
> **注意**：在实际模拟中，需确保读写头位置 `pos` 不会超出列表边界。
