## [Page 3-4] 实验任务：构建交互式计算器与时钟
本周目标是将静态的 HTML 骨架转化为可交互的工具：
1.  **计算器功能**：读取用户输入、识别运算选择、展示计算结果。
2.  **动态时钟**：利用 Date 对象获取系统时间，并通过动画循环实现秒级更新。

### 核心知识模块
*   **DOM 操作**：代表 HTML 元素的 JavaScript 对象。
*   **事件机制**：`onclick` 响应与用户行为捕获。
*   **内置对象**：Array（函数数组）、Date（时间处理）。
*   **异步控制**：`setTimeout` 与网页动画原理。

## [Page 7-9] 文档对象模型 (DOM)：HTML 元素的软件映射
JavaScript 将每一个 HTML 标签视为一个“对象”，通过属性与方法进行操控。

### 1. 元素获取与内容修改
*   **获取对象**：`var x = document.getElementById("result");`
*   **内容读写**：通过 `x.innerHTML` 修改起始与终止标签间的文本内容。

## [Page 10-11] 事件驱动编程：赋予网页响应力
网页的交互本质上是“事件-响应”机制。

### 常用事件响应
*   **点击事件 (`onclick`)**：常用于按钮触发计算逻辑。
*   **输入事件 (`oninput`)**：实时捕获用户在文本框中的键入。
*   **加载事件 (`onload`)**：确保脚本在页面资源加载完毕后运行。

## [Page 17-22] 网页动画原理：`setTimeout` 的异步魔法
为了让时钟“动”起来，我们需要引入时间维度。

### 1. `setTimeout` 函数
*   **语法**：`setTimeout(callback, delay_ms)`。
*   **机制**：非阻塞式调用。告知浏览器在指定延迟后执行回调函数，脚本会立即继续向下执行。

### 2. 递归调用实现循环
在 `run_clock` 函数末尾再次调用 `setTimeout(run_clock, 1000)`，即可实现每秒一次的动态刷新。

### 3. 注意事项：值传递与地址传递
*   传递**数字**时，`setTimeout` 锁定的是当前值的副本。
*   传递**对象（如数组）**时，锁定的是内存地址。若对象属性在延迟期间发生变化，回调函数执行时将读取到更新后的值。

## [Page 23-24] 高级调试：`console.log` 的深度诊断
除了简单的字符串，`console.log` 还可以：
*   **检视复杂对象**：打印 NodeList 或自定义对象的完整属性树。
*   **格式化输出**：支持 `%d`（整数）、`%f`（浮点数）、`%s`（字符串）及 `%o`（对象）占位符。

## [Page 29-34] 补充材料：JavaScript 语言特性概览

### 1. 弱类型与动态性
变量使用 `var` 声明，无需预设类型，可随时重新赋值为不同类型的数据。

### 2. 运算符差异
*   **全等运算符 (`===`)**：不仅比较值，还要求类型一致，比 `==` 更安全。
*   **逻辑与位运算**：采用 `&&`、`||`、`!` 以及无符号右移 `>>>`。
*   **三元运算符**：`条件 ? 真值 : 假值`，是 `if-else` 的简洁写法。

## [Page 35-37] 流程控制：循环与分支
*   **while/for**：与 Python 逻辑一致，但注意括号与大括号的使用规范。
