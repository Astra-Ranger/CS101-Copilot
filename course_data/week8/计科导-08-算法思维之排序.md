## Bubble Sorting Algorithm

**Input:** An array \(A\) of integers \(A = A[1], A[2], \ldots, A[n]\)  
**Output:** A reordering of A’s elements into \(A = A[i_1], A[i_2], \ldots, A[i_n]\), such that \(A[i_1] < A[i_2] < \ldots < A[i_n]\)  
**Steps:**

```text
for i = 1 to n − 1
    for j = 1 to n − i
        if A[j]>A[j+1]
            exchange A[j] with A[j+1]
```

## 冒泡排序算法（下面7行构成了规则）

**输入：** 待排序的数组 \(A\)，数组 \(A\) 的长度为 \(n\)。  
**输出：** 排好序的数组 \(A\)。  
**算法步骤描述：**（即对计算过程的描述）

```text
for i = 1 to n − 1
    for j = 1 to n − i
        if A[j]>A[j+1]
            exchange A[j] with A[j+1].
```

## 冒泡排序算法

**输入：** 包含 \(n\) 个不同整数的数组 \(A\)。  
**输出：** 元素从小到大排好序的数组 \(A\)。

```text
for i = 1 to n − 1
    for j = 1 to n − i
        if A[j]>A[j+1]
            exchange A[j] with A[j+1]
```

## Partition算法

**输入：** 整数数组 \(A\)，左端点 \(p\)、右端点 \(r\)  
**结果：** 划分成三组，\(A[p:i]\), \(A[i]\), \(A[i+1:r]\)  
**输出：** 标杆 \(A[r]\) 的最终位置 \(i\)

> **问题**描述，将输出细化为结果和函数返回值（输出）

```python
def partition(A, p, r):
    i = p
    for j in range(p, r):
        if A[j] < A[r]:    # 用A[r]作为标杆
            A[i], A[j] = A[j], A[i]
            i += 1
    A[i], A[r] = A[r], A[i]
    return i
```

> 高德纳的《计算机程序设计的艺术》

>
> 算法复杂度：**最坏情况**下所需的操作数，用渐进符号表示  
> 冒泡排序算法：算法复杂度是 \(O(n^2)\)
>
> - 需要 \(n-1+n-2+\cdots+1=n\times(n-1)/2\) 次比较操作
> - 最坏情况下需要 \(n(n-1)/2\) 次交换操作
>   - \(n, n-1, \ldots, 2, 1\)

## 冒泡排序算法

**输入：** 待排序的数组 \(A\)，数组 \(A\) 的长度为 \(n\)。  
**输出：** 排好序的数组 \(A\)。  
**算法描述：**（一般用有限行伪代码）

\[
\begin{aligned}
&\text{for } i=1 \text{ to } n-1\\
&\quad \text{for } j=1 \text{ to } n-i\\
&\quad\quad \text{if } A[j] > A[j+1]\\
&\quad\quad\quad \text{exchange } A[j] \text{ with } A[j+1].
\end{aligned}
\]

## 冒泡排序算法

**输入：** 包含 \(n\) 个不同整数的数组 \(A\)。  
**输出：** 元素从小到大排好序的数组 \(A\)。

\[
\begin{aligned}
&\text{for } i=1 \text{ to } n-1\\
&\quad \text{for } j=1 \text{ to } n-i\\
&\quad\quad \text{if } A[j] > A[j+1]\\
&\quad\quad\quad \text{exchange } A[j] \text{ with } A[j+1]
\end{aligned}
\]

# 3. 重温fastsort算法

- **输入：** 8元素整数列表 d = [8 3 6 7 2 1 4 5]
- **输出：** 8元素整数列表 d = [1 2 3 4 5 6 7 8]
  - 元素从小到大排好序了
- **步骤：** 调用 fastsort(d)，可能不止一个参数

函数 fastsort(A) 的计算过程如下：

1. 基线情况（base case），决定函数什么时候结束：  
   如果 A 只包含 0 个元素（如 []）或 1 个元素（如 [3]），fastsort(A) 结束
2. 选择 A 的最后一个元素作为标杆元素，简称标杆（pivot）
   - 如列表 [8 3 6 7 2 1 4 5] 中的 5
3. 调用划分函数 partition
   - 将小于标杆元素的元素放入 lowerA 子列表（称为小数组），  
     将大于标杆元素的元素放入 upperA 子列表（称为大数组）
4. 递归调用 fastsort(lowerA)
5. 递归调用 fastsort(upperA)

```text
A = [8 3 6 7 2 1 4 5]
              ↓
          partition
          ↙        ↘
lowerA = [3 2 1 4]   upperA = [6 7 8]
```

分治第一层，划分比较平衡：

```text
d = [8 3 6 7 2 1 4 5]
        ↓              ↓
d = [3 2 1 4] 5 [6 7 8]
```

分治第二层，划分不平衡：

```text
d = [3 2 1] 4 [] 5 [6 7 8]
```

```text
d = [] 1 [2 3] 4 5 [6 7 8]
d = 1 [2] 3 [] 4 5 [6 7 8]
d = 1 [] 2 [] 3 4 5 [6 7 8]
d = 1 2 3 4 5 [6 7] 8 []
d = 1 2 3 4 5 [6] 7 [] 8
d = 1 2 3 4 5 [] 6 [] 7 8
d = 1 2 3 4 5 6 7 8

# 快速排序算法 quicksort 需要多少次比较操作？

- 最坏情况：\(n \times (n - 1) / 2\)  最坏情况下算法复杂度为 \(O(n^2)\)

- 平均情况：？

- 考虑 \(n\) 个数的快排算法，记 \(T(n)\) 为平均意义下的比较次数，有递推式

- \[
T(n)=\frac{1}{n}\sum_{k=1}^{n}\left(T(k-1)+T(n-k)+n-1\right)
\]

  \[
=\frac{2}{n}\sum_{k=1}^{n-1}T(k)+n-1
\]

  \[
\frac{T(n)}{n+1}=\frac{T(n-1)}{n}+\frac{2(n-1)}{n(n+1)}
\]

  \[
\frac{2(n-1)}{n(n+1)}=\frac{2}{n+1}-\frac{2}{n(n+1)}
\]

- \(T(n) \approx 2(n+1)\ln n\)  平均情况下算法复杂度为 \(O(n\log n)\)
