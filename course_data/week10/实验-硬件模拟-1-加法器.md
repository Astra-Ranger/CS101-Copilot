# 全加器 Full Adder

- 一位全加器
  - 可以将**两个一位二进制数（A/B）**和**低位进位（Cin）**相加，并产生**当前位之和（S）**以及**高位进位（Cout）**的组合逻辑电路
  - 设计一位全加器
    - 根据真值表推导逻辑表达式

$$
\begin{aligned}
S &= (\neg A \land \neg B \land C_{in}) \lor (\neg A \land B \land \neg C_{in}) \lor (A \land \neg B \land \neg C_{in}) \lor (A \land B \land C_{in}) \\
&= \neg A \land ((\neg B \land C_{in}) \lor (B \land \neg C_{in})) \lor A \land ((\neg B \land \neg C_{in}) \lor (B \land C_{in})) \\
&= \neg A \land ((\neg B \land C_{in}) \lor (B \land \neg C_{in})) \lor A \land (\neg\neg((\neg B \land \neg C_{in}) \lor (B \land C_{in}))) \\
&= \neg A \land ((\neg B \land C_{in}) \lor (B \land \neg C_{in})) \lor A \land (\neg((\neg B \land C_{in}) \lor (B \land \neg C_{in}))) \\
&= \neg A \land (B \oplus C_{in}) \lor A \land \neg(B \oplus C_{in}) \\
&= A \oplus B \oplus C_{in}
\end{aligned}
$$

$$
C_{out} = \cdots = (A \land B) \lor (C_{in} \land (A \lor B))

# 2. 超前进位加法器 Carry-Lookahead Adder

- 超前进位加法器
  - 波纹进位加法器运算延迟大
    - 进位信号由低位向高位串行传输，高位计算依赖于低位计算的结果
  - 消除由于进位信号串行传输所需的时间
    - 以 4 位加法器为例，定义从低位到高位四个 1 位全加器的进位输入信号（`Cin`）分别为 $C_{-1}, C_0, C_1, C_2$，对应的进位输出分别为 $C_0, C_1, C_2, C_3$，可以得到进位信号逻辑表达式

\[
\begin{cases}
C_0 = (A_0 \land B_0) \lor (C_{-1} \land (A_0 \lor B_0)) \\
C_1 = (A_1 \land B_1) \lor (C_0 \land (A_1 \lor B_1)) \\
C_2 = (A_2 \land B_2) \lor (C_1 \land (A_2 \lor B_2)) \\
C_3 = (A_3 \land B_3) \lor (C_2 \land (A_3 \lor B_3))
\end{cases}
\]

# 超前进位加法器 Carry-Lookahead Adder

- 超前进位加法器
  - 波纹进位加法器运算延迟大
    - 进位信号由低位向高位串行传输，高位计算依赖于低位计算的结果
  - 消除由于进位信号串行传输所需的时间
    - 使用 $P_i$（Propagate）表示传播信号：为真表示要**传播**低位进位信号
    - 使用 $G_i$（Generate）表示生成信号：为真表示要**生成**进位信号

$$
\begin{cases}
C_0 = \textcolor{red}{(A_0 \land B_0)} \lor \left(C_{-1} \land \textcolor{purple}{(A_0 \lor B_0)}\right) \\
C_1 = \textcolor{red}{(A_1 \land B_1)} \lor \left(C_0 \land \textcolor{purple}{(A_1 \lor B_1)}\right) \\
C_2 = \textcolor{red}{(A_2 \land B_2)} \lor \left(C_1 \land \textcolor{purple}{(A_2 \lor B_2)}\right) \\
C_3 = \textcolor{red}{(A_3 \land B_3)} \lor \left(C_2 \land \textcolor{purple}{(A_3 \lor B_3)}\right)
\end{cases}
\qquad
\begin{cases}
P_i = \textcolor{purple}{(A_i \lor B_i)} \\
G_i = \textcolor{red}{(A_i \land B_i)}
\end{cases}
$$

# 3. Python 面向对象基础

- 面向对象（Object Oriented）与面向过程（Procedure Oriented）
  - 我们前面小班课编写的程序都是面向过程程序
    - 将问题拆解为具体的步骤
  - 面向对象将数据和操作数据的行为视为一个整体（对象）
    - 类：描述一类对象的共同特征和行为，定义了对象的属性（数据成员）和方法（函数）
    - 对象：是类的具体实例，可以独立存储数据并执行类中定义的方法

```python
>>> # Cat 是一个类
>>>
>>> my_cat   = Cat(name='Choco')   # 创建了一个对象 my_cat   并存储了数据： 属性 name 为 Choco
>>> your_cat = Cat(name='Vanilla') # 创建了一个对象 your_cat 并存储了数据： 属性 name 为 Vanilla
>>>
>>> my_cat.print_name() # 执行类中定义的方法 print_name, 输出 name 属性的值
Choco
>>> your_cat.greet() # 执行类中定义的方法 greet
=Meow=

# Python 面向对象语法

```python
class Cat: # 使用 class 关键字定义一个类 Cat
    def __init__(self, name): # 构造函数，在创建对象时调用，Cat(name='Choco')
        self.name = name      # 类 Cat 有一个属性 name，其值为构造函数的参数 name

    def print_name(self): # 类方法 print_name
        print(self.name)  # 输出当前对象中的 name 属性

    def greet(self): # 类方法的第一个参数 self 表示调用该类方法的具体实例对象
        print('=Meow=')
```

- 类好比是一个模板，定义了通用的行为
- 对象是根据类模板填充数据后的一个实例
  - `print_name` 方法是类中的通用行为（没有与数据绑定）
  - 输出名字需要访问属性 `name` （具体的数据）
  - Python 中类方法第一个参数固定为 `self`，表示调用该方法的对象
  - 通过 `self.name` 可以获取属性 `name`
  - `my_cat.print_name()` 相当于 `Cat.print_name(my_cat)`
