## [Page 3-6] 一位全加器（Full Adder）的设计

一位全加器（FA）是组合逻辑电路的核心，负责将两个一位二进制数（A、B）与低位进位（Cin）相加。

### 1. 真值表与逻辑推导
通过真值表，我们可以导出和（S）与进位输出（Cout）的逻辑表达式：

| A | B | Cin | S (Sum) | Cout (Carry) |
|---|---|-----|---|---|
| 0 | 0 | 0 | 0 | 0 |
| 1 | 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 1 | 1 |

### 2. 逻辑表达式优化
利用异或（XOR）运算简化表达式：
*   **和（S）**：$ S = A \oplus B \oplus C_{in} $
*   **进位输出（Cout）**：$ C_{out} = (A \land B) \lor (C_{in} \land (A \lor B)) $

## [Page 7-9] 组合逻辑加法器的进位链与延迟分析

### 1. 门延迟（Gate Delay）
在硬件中，信号通过每一级门电路都会产生延迟。分析全加器的关键路径有助于理解性能瓶颈。

### 2. 波纹进位加法器（Ripple Carry Adder, RCA）
RCA 通过串联多个一位全加器实现多位加法。
*   **特点**：低位的进位输出（Cout）作为高位的进位输入（Cin）。
*   **局限性**：由于进位信号必须像“波纹”一样逐级传递，总延迟随位数线性增加，限制了运算速度。

## [Page 10] 时序四位串行加法器结构

串行加法器利用时序电路在不同时钟周期内复用同一个全加器。
*   **核心组件**：
    *   **组合电路 F/G**：分别用于生成求和信号与下一位进位信号。
    *   **D 触发器（D-FlipFlop）**：用于存储并在下一周期提供进位状态（$ C $）。

## [Page 11-13] 超前进位加法器（Carry-Lookahead Adder, CLA）

CLA 通过预先计算每一位的进位信号，消除了串行进位链的延迟。

### 1. 传播与生成信号
*   **生成信号 (Generate)**：$ G_i = A_i \land B_i $（当前位必产生进位）。
*   **传播信号 (Propagate)**：$ P_i = A_i \lor B_i $（当前位可传播低位进位）。

### 2. 超前进位逻辑公式
通过递归展开，每一位的进位仅依赖于 $ P_i $、$ G_i $ 和初始进位 $ C_{-1} $：
*   $ C_0 = G_0 \lor (P_0 \land C_{-1}) $
*   $ C_1 = G_1 \lor (P_1 \land G_0) \lor (P_1 \land P_0 \land C_{-1}) $
*   ...（以此类推，所有进位并行产生）

## [Page 14-15] Python 面向对象编程（OOP）基础

在模拟硬件时，我们利用“类”来描述硬件单元的结构，“对象”来表示具体的硬件实例。

### 1. 核心概念
*   **类（Class）**：硬件设计的模板。
*   **对象（Object）**：具体的电路实例（如 `my_fa = FA()`）。
*   **self 指针**：在类方法中代表当前实例本身。

### 2. 模拟示例
```python
class Cat:
    def __init__(self, name):
        self.name = name  # 属性存储
    def greet(self):
        print(f"{self.name} says: Meow!")
```
